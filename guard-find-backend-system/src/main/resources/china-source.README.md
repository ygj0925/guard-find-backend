# 官方行政区划快照

`china.json` 来自中华人民共和国民政部发布的 **2024 年中华人民共和国县以上行政区划代码**，截止日期为 2024-12-31。2026-11-18 从以下官方 HTTPS 页面直接下载并转换，未使用第三方维护的区划名称或地图供应商的区域列表作为官方代码表：

https://www.mca.gov.cn/mzsj/xzqh/2025/202401xzqh.html

共 3213 个真实代码、34 个省级节点。台湾省、香港特别行政区、澳门特别行政区的市县信息在原表中暂缺，因此保留省级，不补造下级代码。直辖市在原始树中直接下挂区县；小程序级联选择的重复城市列只是展示适配，不新增代码。

原表注 2 说明，名称后缀 `*` 是省（自治区）直辖县级行政区划汇总码的脚注标记，行政名称本身不含该符号。转换器核对该脚注说明及代码第三、四位 `90` 后，仅去除 32 项名称末尾的 `*`（包括济源市、仙桃市、神农架林区及相关海南、新疆直辖县级区划）。未改动行政名称正文或代码。已扫描其余名称，未发现其他待去除脚注；未知星号标注会拒绝导入，不擅自删除。

`china-source.json` 记录发布机构、版本、来源 URL、原 HTML SHA-256 和转换结果 SHA-256。服务读取时核对数据哈希，并在 `/miniapp/region/source` 返回元信息。当前版本明确为 2024 年底；不能称为最新实时数据。

后续官方发布入口：https://dmfw.mca.gov.cn/XzqhVersionPublish.html 。本次该入口返回 403，未据第三方数据猜测 2025/2026 年变更。后续维护需从官方渠道获取可核验的发布版本，检查代码变更后再更新；不得在用户请求中实时抓取此站。

复现本版本：从官方地址下载 HTML，再在 backend 根目录运行：

```powershell
py -3 scripts/import-official-regions.py downloaded.html --version 2024-12-31 --source https://www.mca.gov.cn/mzsj/xzqh/2025/202401xzqh.html
```

脚本校验官方域名、重复代码、34 省级和最低记录数量，再输出树与元信息；未来官方若改为其他格式，应先调整并核验转换器，而非强行沿用 HTML 解析。

房源新增 `region_code` 为可选字段。历史房源的文字 city/district 不被猜测更新；用户重新选择官方区划时，服务端根据代码确定城市和区县。历史合同快照不受影响。
